# Incident Response

1. Pause new payment preparation if configuration or reconciliation is unsafe.
2. Preserve read-only access to existing bills and transaction evidence.
3. Compare database, Horizon, contract, and biller-provider state.
4. Rotate exposed provider or database credentials.
5. Repair only records supported by independent settlement evidence.
6. Record impact, resolution, and prevention actions.

Never request a user's secret key during support or recovery.
